# Work with databases in CouchDB.

Work with databases in CouchDB.

## Details

There are the following functions for working with databases:

- [`db_create()`](https://docs.ropensci.org/sofa/reference/db_create.md) -
  Create a database

- [`db_delete()`](https://docs.ropensci.org/sofa/reference/db_delete.md) -
  Delete a database

- [`db_info()`](https://docs.ropensci.org/sofa/reference/db_info.md) -
  Get info for a database

- [`db_list()`](https://docs.ropensci.org/sofa/reference/db_list.md) -
  List databases

- [`db_replicate()`](https://docs.ropensci.org/sofa/reference/db_replicate.md) -
  Replicate a database from one couch to another
